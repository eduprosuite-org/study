Designing DWV Isometric Drawings

Written by John Masterson
Published: 2026-08-13
Fact Checked

Isometric drawings represent three-dimensional piping runs on a two-dimensional surface. Most master and journeyman exams require you to interpret or draw an isometric routing map to prove you can layout venting configurations.

1. Isometric Drawing Rules

Isometric drawing uses specific angles to represent depth and elevation:

  • Vertical Lines: Run straight up and down, representing vertical stack piping.
  • 30-Degree Lines: Run at a 30-degree angle from the horizontal to represent horizontal runs going north/south or east/west.
  • No Horizontal Lines: True isometrics contain absolutely no flat horizontal lines.

2. Labeling Fixtures and Vents

When drafting isometrics for exam grading, you must explicitly mark:

  1. The location of fixture traps and trap arms.
  2. Where vents tie into the drainage system (vent connections).
  3. Directions of flow (indicated by arrows).
  4. Pipe sizes and pipe sizing transitions.

3. Sizing Vents on Isometrics

You must size each section of waste and vent lines on the isometric drawing using the DFU tables. Make sure that your vent stack terminals extend through the roof by at least **6 inches** (or more depending on frost closure rules, which require 10-inch extensions in cold regions).
