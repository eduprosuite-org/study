Technical Specification of WiFi QR Code Formatting

WiFi QR codes adhere to the standardized MECARD/ZXing wireless configuration format. When parsed by mobile operating systems (iOS CoreImage barcode parser and Android ML Kit Vision Barcode API), the payload triggers an internal system dialogue enabling one-tap association with the specified Access Point (AP).

⚙️ Standard WiFi Payload Schema

WIFI:S:<SSID>;T:<WPA|WEP|nopass>;P:<PASSWORD>;H:<true|false>;;

Special characters such as colons (:), semicolons (;), and backslashes (\) in passwords must be escaped with a backslash.

1. WiFi Security Protocols Comparison

Choosing the correct security type is essential to prevent authentication handshaking errors when users scan your code:

Security Protocol Schema Token Encryption Standard Device Compatibility Security Recommendation
WPA2 / WPA3 Personal T:WPA; AES-CCMP / SAE (128/256-bit) iOS 11+, Android 10+, Windows 11 Highly Recommended (Standard)
WEP (Wired Equivalent) T:WEP; RC4 Stream Cipher (40/104-bit) Legacy devices only Deprecated (Vulnerable to cracking)
Open / Captive Portal T:nopass; Unencrypted (No Password) Universal (All mobile OS) Suitable for cafes & public guest networks

Frequently Asked Questions

How do guests connect to WiFi using a QR code?
Guests simply open the native camera app on iOS or Android and point it at the QR code. A banner notification will prompt them to tap 'Join Network' to connect instantly without typing any password.
Is my WiFi password secure on this generator?
Yes, 100% secure. The generator runs entirely within your browser (client-side JavaScript). Your SSID and network password are never transmitted over the internet or saved to any remote server.
What encryption standard should I choose for modern routers?
Choose 'WPA/WPA2' for standard home and office routers. If your network is an open public hotspot without credentials, choose 'None (Open)'.
Can hidden WiFi networks be encoded into a QR code?
Yes. Check the 'Hidden Network' checkbox in our tool. It appends the 'H:true;' parameter to the WiFi schema string, instructing mobile devices to broadcast probe requests for non-beaconing SSIDs.
