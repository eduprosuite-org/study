ISO/IEC 18004 Character Encoding Modes & Data Density

The QR code standard supports four internal encoding modes to convert characters into binary streams with maximum compaction efficiency:

Encoding Mode Supported Character Set Bits per Character Max Theoretical Capacity (Version 40-L)
Numeric Mode Digits 0 – 9 only ~3.33 bits / char (10 bits per 3 digits) 7,089 Characters
Alphanumeric Mode 0–9, A–Z, Space, $, %, *, +, -, ., /, : 5.5 bits / char (11 bits per 2 chars) 4,296 Characters
Byte / Binary Mode Full ISO-8859-1 & UTF-8 (All symbols, emojis, lowercase a-z) 8.0 bits / byte 2,953 Bytes
Kanji Mode Shift JIS Double-Byte Japanese Characters 13.0 bits / char 1,817 Characters

Static Offline QR vs Server-Dependent Dynamic QR

Understanding the architectural difference between static raw text encoding and dynamic redirected links:

Feature Static Plain Text QR Dynamic URL Redirect QR
Data Storage Stored 100% inside printed dots Stored on an intermediary cloud server
Internet Requirement Zero (Scans offline in airplane mode) Requires active mobile internet
Privacy & Security Maximum (No tracking, no external logs) Tracks IP, device type, timestamp
Expiration Risk Never expires (Permanent forever) Expires if cloud subscription lapses

Frequently Asked Questions

What happens when someone scans a plain text QR code?
When scanned by a smartphone camera or handheld barcode scanner, the exact raw text is displayed directly on the screen. Users can copy the text, search it on Google, or save it to their notes without requiring an internet connection.
How many characters can be stored in a plain text QR code?
Under the ISO/IEC 18004 specification, a Version 40 QR code can store up to 7,089 numeric characters, 4,296 alphanumeric characters, or 2,953 binary/byte characters (UTF-8). For optimal mobile camera readability, keeping text under 300 characters is recommended.
Can I generate SMS QR codes that pre-fill a text message?
Yes. By formatting the payload using the SMSTO:[phone]:[message] syntax, scanning the QR code immediately opens the native SMS texting app with the destination number and body message pre-typed.
Does a plain text QR code require an active internet connection to scan?
No. Unlike URL QR codes which must load a webpage over HTTP/HTTPS, plain text QR codes store all character data completely offline inside the optical dots.
