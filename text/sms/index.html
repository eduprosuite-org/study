SMS URI Scheme Standards & Use Cases

SMS QR codes encode phone numbers and message drafts using the standard SMSTO and sms: URI schemes recognized by Apple iOS CoreImage and Android intent parsers.

📱 SMS QR Code Protocol Syntax

SMSTO:<PHONE_NUMBER>:<MESSAGE_BODY>

Frequently Asked Questions

How does an SMS QR code work?
An SMS QR code encodes a specialized SMSTO URI protocol (SMSTO:phonenumber:messagetext). When scanned by any smartphone camera, the device automatically opens its native Messages app with the recipient number and message text pre-populated.
Can SMS QR codes be used for opt-in marketing?
Yes. Businesses frequently use SMS QR codes for text-to-join loyalty clubs, coupon redemptions, and keyword opt-ins (e.g. 'JOIN' or 'START').
Does the user get charged just for scanning the QR code?
No. Scanning simply opens the text message composer. The SMS is only transmitted if the user manually taps the send arrow button on their device.
